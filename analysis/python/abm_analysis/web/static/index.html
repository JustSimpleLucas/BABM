BABM Market statistics

Select a run

Every archived run under the data root is listed on the left. Choosing one recomputes its statistics from the run's own artefacts — the same functions that write the exported CSV tables — with one column per traded market.

Tick two or more runs and press Compare to read them as a cohort: runs that differ only in the seed are aggregated into one condition with its dispersion and reproduction rates, and runs that differ in a control become separate conditions side by side. A calibration study, when the archive holds one, is listed beneath the runs.
